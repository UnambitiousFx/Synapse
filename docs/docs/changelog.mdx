# Changelog

This page records issues discovered and resolved while hardening the library. All entries are fully resolved — none represent open bugs. The detailed engineering notes for each fix live in [`docs/known-issues/`](https://github.com/UnambitiousFx/Synapse/tree/feature/typed-pipeline-behaviors/docs/known-issues) (mirrors the GitHub bug-report template; kept as a developer reference).
